# Формирование кластеров

## Кластер игрового поля
1) Map - игровое поле в виде матрицы, содержащее игровые фигуры.

## Кластер игровой логики
1) GameLogicObserver - наблюдатель за состоянием игрового поля, для поиска комбинаций фигур.

## Кластер действий игрока и бонусных "умений"
1) Action - общая структура для пользовательских команд. На основе одноименного шаблона проектирования.
2) ActionHistory - история действий игрока.
3) Action - действие игрока по перемещению фигур на игровой доске.
4) ExtraAction - дополнительные действия, которые даются игроку за сбор определенной комбинации фигур.
Позволяют убрать все фигуры в ряду или же убрать определенный тип фигур.

## Кластер стандартной библиотеки проекта
1) Matrix - реализации матрицы для игрового поля.
2) Queue/Dequeue - для реализации истории ходов пользователя. Дек можно использовать для реализации отмены хода.

## Кластер ввода/вывода
1) InputOutput - фасад над системой ввода/вывода.

## Кластер системы очков пользователя и бонусов
1) ScoreSystem - фасад для системы очков пользователя.
2) Statistics - статистика игры.
3) FigureCombinations - тип возможных комбинаций фигур. Связаны с бонусами.
