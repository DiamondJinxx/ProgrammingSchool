# Выделение классов проектирования

1) GameLogicObserver - наблюдатель за состоянием игрового поля, для поиска комбинаций фигур.
2) Action - общая структура для пользовательских команд. На основе одноименного шаблона проектирования.
3) InputOutput - фасад над системой ввода/вывода.
4) ScoreSystem - фасад для системы очков пользователя.
