# Задание 1

**Игровое поле.** Матрица игровых элементов. Хранит расположение игровых объектов.

**Игровой объект.** Непосредственно ячейка в игровом поле. Содержит текстовое представление(буквы A, B, C, D, E). Перемещается после пользовательского ввода.

**Статистика.** Инкапсулирует логику подсчета статистики и истории хода игрока.

**Интерфейс пользовательского ввода.** Отвечает за ввод координат пользователем и выбор ячейки для перемещения.

**Интерфейс пользовательского вывода.** Отвечает за вывод игрового поля на экран, вывод конечной статистики игровой сессии.

**Игровая логика**. Отвечает за инициализацию сетки, проверки комбинаций и удаления элементов, генерацию новых элементов. Механику бонусов так же хочу реализовать здесь.
