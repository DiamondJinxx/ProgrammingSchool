# Шаг 4

**Map** - игровое поле в виде матрицы, содержащее игровые фигуры. Использует класс Matrix через композицию.

**GameLogicObserver** - наблюдатель за состоянием игрового поля, для поиска комбинаций фигур.

**Action** - общая структура для пользовательских команд. На основе одноименного шаблона проектирования. Абстрактный класс
**UserAction** - действие игрока по перемещению фигур на игровой доске. Наследуется от абстрактного Action.
**ExtraAction** - дополнительные действия, которые даются игроку за сбор определенной комбинации фигур. Наследуется от абстрактного Action.


**ActionHistory** - история действий игрока. С помощьью Queue/Dequeue хранит АТД Action.

**Matrix** - реализации матрицы для игрового поля. Не абстрактный.

**Queue/Dequeu**e - для реализации истории ходов пользователя. Дек можно использовать для реализации отмены хода. Абстрактный, реализация либо на массиве, либо на списке, при необходимости оптимизаций.

**InputOutput** - фасад над системой ввода/вывода.

**ScoreSystem** - фасад для системы очков пользователя. Не абстракный.
**Statistics** - статистика игры. Не абстрактный. Композицией работает с системой очков.

**FigureCombinations** - тип возможных комбинаций фигур. Абстрактный. Наследники - реализации конкретных комбинаций.

# Шаг 5

## Map
**Команды**
- установить набор фигур
- установить фигуру по координатам
- убрать фигуру по координатам
- сдвинуть часть столбца на освободившиеся места
**Запросы**
- вывод карты на экран
  
## Matrix
**Команды**
- Установить элементы в матрице
- установить элемент по координатам
- убрать элемент по координатам
- сдвинуть часть столбца на освободившиеся места
**Запросы**
- Получить копию текущего состояния матрицы

## Queue/Dequeue
**Команды**
- положить элемент в начало
- добавить элемент в конец
- удалить элемент из начала
- удалить элемент из конца
**Запросы**
- получить элемент из начала очереди
- получить элемент из конца очереди

## ActionHistory
**Команды**
- записать действие пользователя
**Запросы**
- получить последнее действие пользователя
- получить последовательность действий пользователей

## ScoreSystem
**Команды**
- зачислить очки
**Запросы**
- получить общее количество очков пользователя

## Statistics
**Команды**
- увеличить счетчик ходов пользователя
- зачислить очки
**Запросы**
- получить общее числов ходов пользователя
- получить общее число очков пользователя

## InputOutput
**Команды**
- вывод игрового поля
- вывод сообщений пользователю
- вывод статистики
**Запросы**
- ввод действия пользователя

## GameLogicObserver
**Команды**
- удалить комбинацию фигур с поля
- начислить очки за собранную комбинацию
**Запросы**
- имеются ли на игровом поле ходы
- собрал ли пользователь комбинацию фигур
