# Схемы создания объектов
Объект **Map** создается один раз в момент старта игры.
Объект **GameLogicObserver** создается один раз в момент старта игры.
**ActionHistory** создается в момент старта игры.

**ScoreSystem** создается один раз в момент старта игры.
**Statistics** создается один раз в момент старта игры.

**UserAction** создается в момент действия пользователя.
**ExtraAction** создается при сборе пользователем определенных комбинаций фигур.

**FigureCombinations** наследники создаются в момент старта игры.

# Обработка событий
Событие "Игрок сделал ход". Обработчики:

    - Перемещается фигура на карте
    - Проверяется наличие собранной комбинации фигур
    - Увеличивается счетчик действий в статистике
    - Ход записывается в историю ходов

Событие "Собрана комбинация фигур". Обработчики:

    - Сбор фигур с карты
    - Начисление очков в статистику
    - Генерация новых фигур на карте

Событие "Игрок использовал бонусное действие". Обработчики:

    - Сбор фигур с карты
    - Начисление очков в статистику
    - Генерация новых фигур на карте
