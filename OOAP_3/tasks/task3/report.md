# Выделение основных классов анализа

1) Map - игровое поле в виде матрицы, содержащее игровые фигуры.
2) Figure - игровая фигура, располагающаяся на игровой поле.
3) Statistics - статистика игры.
4) ActionHistory - история действий игрока.
5) Action - действие игрока по перемещению фигур на игровой доске.
6) Scores - очки, получаемые игроком за "собираемые" комбинации фигур.
7) Bonus - мультипликатор, учитывающийся при собирании игроком комбинации фигур.
8) FigureCombinations - тип возможных комбинаций фигур. Связаны с бонусами.
